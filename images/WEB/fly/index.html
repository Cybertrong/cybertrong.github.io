dans les bars, cafés, événements culturels, divertissements, services, touristiques, etc.

MISSION

FLY est une plateforme visuelle interactive permettant la diffusion de promotions urbaines variées* aidant les utilisateurs à trouver rapidement l’offre qu’ils cherchent sans perdre de temps sur Internet, FLY est une évolution technologique du traditionnel Flyer.


* Ici Grande région de Montréal.

COMBIEN

Gratuit pour les utilisateurs, l’application se veut payante au moment de la création de badges. Le coût est de 5$ par badge et l’achat se fait directement avec le compte itunes de l’utilisateur.
