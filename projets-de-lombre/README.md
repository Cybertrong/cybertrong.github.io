# Projets de l'Ombre

Site de la compagnie Projets de l'Ombre (théâtre visuel, danse et marionnette, sous la direction de Marie-Pascale Bélanger).

Un seul fichier `index.html` et un dossier `images/`. Les pages (Accueil, Spectacle, Dossier de presse, Direction artistique, Calendrier) s'affichent via les ancres `#spectacle`, `#presse`, `#direction`, `#calendrier`.

## Mettre en ligne avec GitHub Pages

Settings → Pages → Source : « Deploy from a branch », branche `main`, dossier `/ (root)`.
